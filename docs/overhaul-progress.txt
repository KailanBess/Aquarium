Aquarium ecosystem overhaul — progress on November 26, 2026

Scope
Aquarium, FishTank, FishBowl, FishNet, shared Core, standalone utilities and future Shoal integration remain in scope. CloudKid/music identification and Tailscale/private networking remain excluded. Both supplied specification attachments were read in full and reconciled into 887 requirements. The full overhaul is unfinished; needs-audit does not imply a feature is absent.

Published releases
Aquarium 0.9.0 — https://github.com/KailanBess/Aquarium/releases/tag/v0.9.0
Includes Core 0.3.0, independent Windows utilities, bundled FishNet 0.6.3 and FishTank 0.18.0. System Monitor 1.1.0 adds the last 900 in-memory CPU/RAM/process-count entries, explicit pause/resume/failure markers, UTC timestamps, collection sequence, dropped-entry counts and explicit atomic JSON history export. History contains no process names/IDs and is discarded when the monitor closes. Live snapshot export retains its separate process-name warning. Delayed captures cannot cross pause/resume boundaries. The history window supports enlarged text and scrolling in small windows.
Retains package installation/repair/rollback, offline .aqpkg validation, bounded diagnostics, safe explicit unknown/unavailable/unsupported observations, versioned Settings SDK, appearance undo, local support export and encrypted record backup/recovery. Custom FishNet profile selectors block managed removal so user data can be preserved. Independent tools need no running hub or account.

FishNet 0.6.3 — https://github.com/KailanBess/FishNet/releases/tag/v0.6.3
Local photo/PDF catalogs, albums, imported-screenshot filename/folder filtering, slideshow, metadata, zoom, crop/rotate/brightness copy export and bounded native PDF rendering. Exact-content duplicate candidates use file length and SHA-256 for current filters, bounded to 10,000 paths, 64 MiB per file and 2 GiB of reads. Skipped/partial coverage and cancellation remain explicit; JSON reports require a save. No photo deletion, catalog mutation, automatic upload or perceptual matching is claimed. Conversion publishes completed temporary output atomically and preserves source/prior destination on failure/cancellation. Save pickers use path-only results and explicit default extensions. Original media, playlists, audio/video, radio, podcasts and queues are preserved.

FishTank 0.18.0 preview — https://github.com/KailanBess/FishTank/releases/tag/preview-v0.18.0
Supported current-user Windows camera/microphone ConsentStore permission and access-interval metadata in UTC. Open, closed, inconsistent and missing records remain distinct; open records are not live-use proof. No content capture or permission changes.

FishBowl 1.33.0 — https://github.com/KailanBess/FishBowl/releases/tag/v1.33.0
Windows Play → More → Performance and battery provides verified session CPU/working-set observations and Windows battery estimates. Changed/incomplete/reused processes stay unknown. FPS, GPU, temperatures, power and measured battery consumption are not supplied by this panel. Windows app/installer/source and Linux tarball/AppImage are published; maintainer handoff is updated.

Dependency and license review
Sixteen tracked package declarations were inventoried across the four .NET apps. Twenty-eight projects were examined for local restore snapshots; 13 snapshots describe 42 distinct package versions, while 15 projects lack snapshots. Reports retain project/assets hashes, package content hashes, project associations, 25 license expressions, 13 license-file references/hashes and legacy URLs. Four packages lack a modern license element; three provide legacy URLs, while Aquarium.Core 0.2.0 provides neither. The downloaded FishNet 0.6.3 package includes TagLib and third-party notices. This is a partial inventory, not a compliance decision, complete binary SBOM or advisory assessment. Freshness, native/manual components, obligations and vulnerability review remain open.

Provenance
Public source identities and downloaded checksum manifests match GitHub release asset digests. Exact asset URLs/hashes are in published-releases.json. Releases remain unsigned development distributions; signing and independent protection certification are not configured or claimed. Hash consistency is not publisher authentication.
